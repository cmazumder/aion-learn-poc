# XYZ-1 Payment Terminal Technical Specifications

## General

- **Model:** XYZ-1
- **Vendor:** PayTronics

## Hardware

- **Processor:** ARM Cortex-M4
- **Memory:** 256 MB RAM
- **Display:** 5-inch color touchscreen
- **Card Reader:** NFC, RFID, Magnetic Stripe

## Software

- **Operating System:** Embedded Linux
- **Driver Version:** 3.2.1 (known memory leak issue, see JIRA CO-124)
