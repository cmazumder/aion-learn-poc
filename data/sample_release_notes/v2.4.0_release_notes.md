# Firmware v2.4.0 Release Notes

**Date:** 2025-11-01

## New Features

- **Improved TLS Security:** The TLS implementation has been updated to improve security and address the vulnerability identified in JIRA CS-101.
- **New Payment Terminal Driver:** Includes a new driver for the XYZ-1 payment terminal to address the memory leak issue. See JIRA CO-124.

## Bug Fixes

- **Thermal Throttling:** The thermal throttling logic has been adjusted to be less aggressive, resolving the slow charging issue from JIRA CO-123.

## Known Issues

- A `SignatureMismatch` error has been reported during the update process on some stations. See JIRA CO-126.
