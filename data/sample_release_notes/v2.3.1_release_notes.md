# Firmware v2.3.1 Release Notes

**Date:** 2025-10-20

## New Features

- **Thermal Throttling:** Introduced a new power management feature to prevent overheating. See JIRA CO-119.

## Bug Fixes

- Fixed an issue where the station would not report meter values correctly.

## Known Issues

- The new thermal throttling logic may be too aggressive in some situations, leading to slower than expected charging speeds. See JIRA CO-123.
