# PR #4567: Fix race condition in SpoolerVaultAuth

**Author**: Jane Smith
**Jira Ticket**: [CO-127](https://jira.chargepoint.com/browse/CO-127)

## Description

This PR addresses a race condition in `SpoolerVaultAuth.api_key_from_machine_id`. If multiple requests arrived concurrently on a newly started service, the call to `self.vault_client.secrets.kv.v2.list_secrets` could fail with an `InvalidPath` exception because the secrets engine was not yet fully mounted and ready.

The fix introduces a lock mechanism around the `list_secrets` call and adds a retry with a backoff. This ensures that even under heavy concurrent load during startup, the method waits for the Vault path to become available instead of failing immediately. This makes the authentication backend more resilient.
